# Known issues register: v0.1 public review release (candidate g8-r10)

Written 2026-10-22. This register accompanies the public review release of the Open Control Stack (all repositories are public). It is non-authorizing. Publication and production stay on HOLD; no production use, certification or security clearance is claimed or implied, and nothing here says the stack is suitable for any use beyond review of a bounded synthetic reference. The authoritative statements of scope are [guarantees and limits](../guarantees-and-limits.md) and [release status](../release-status.md); this page lists issues, it does not restate or widen those claims.

## How to read this release

This is a public review release of a bounded synthetic reference. It is not a product release, it is not production, and it carries no certification or security clearance; it is not enterprise-grade. The PASS result is over the reduced mandatory claim only; the unreduced mandatory verdict is INCOMPLETE. The qualification was run by the project itself and was not independently audited. Tags named `review-v0.1-g8-r10-20261022` are review markers, not a version or release of the action. Contracts remain `0.1.0-draft`, and no contract freeze is declared by the tags.

## 2. How to read it

Entries are grouped by how they became known. The groups are not a severity ranking and no severity is assigned.

- **Declared**: stated in a repository's documentation or in the pre-registration before or with the run, or recorded as a limit by an owner decision.
- **Observed in review**: found by an independent review round or a spot check after the limits above were declared. The owner classified the wording-scanner items as lint-class (Tier 2) on 2026-10-21 and left them as they are; the other items were deferred or left as recorded. "Tier 2" is the review's own class and is used only where the record uses it.
- **Measured outside the controller**: results of runs that the qualification controller does not collect. They do not enter the verdict and do not qualify any revision.

Status vocabulary: **known limit** (stated limit, kept visible); **declared** (listed in the declared set or pre-registration); **open** (a gap with no fix merged at the listed revision); **fixed-unverified** (fix merged, no controller run has verified the row); **unverified** (could not be confirmed against the repositories while writing this page; kept so that it is not lost).

Verification note: each entry below was checked against the repository text at the revision named, unless marked unverified. Where the check was a reading of code and not an execution, the entry says so. Entries whose only record is the programme's decisions register (a maintainer-held record that is not in this repository; cited below as "maintainer working record (not published)") say that in "Where recorded".
