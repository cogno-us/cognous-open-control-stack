# Stack overview

The stack connects declared actions, institutional authority, bounded execution
and traceable evidence. Its four artifact layers—Declare, Control, Replay and
Evidence—remain useful entry points, but are not a complete inventory of the
selected integration: authority resolution, constrained execution, GAX exchange,
transport, ODES and optional evidence/behavioral layers have distinct owners.

Start with the [README](../README.md), [responsibility map](architecture.md) and
[support status](release-status.md). Runtime implementations live in component
repositories; this hub owns pinned integration scenarios, qualification and
public documentation. The supported workflow is a bounded synthetic reference,
not an authenticated institutional deployment or a production assurance claim.
