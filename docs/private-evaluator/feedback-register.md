## Decision taxonomy

- **DOC**: confusing, missing or incorrect documentation / navigation
- **ARCH**: architecture, trust contract or authority-boundary concern
- **EVID**: missing proof, non-reproducible claim, incomplete scope or evidence provenance
- **COMM**: product fit / adoption / commercial request — not an implicit engineering commitment
- **SEC-PRIVATE**: suspected vulnerability or sensitive exposure — **do not record technical details here**; use the private [security route](../../SECURITY.md).

Status values: proposed / triaged / deferred / investigating / resolved, with an exact owner decision. Evidence class: observed / inferred / hypothesis / unavailable.
