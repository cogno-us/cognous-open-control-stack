## Method and limits

Using GitHub's authenticated repository-file API, fetched the actual file blobs with `ref=<exact selected commit SHA>`, not default-branch/current-main content. A **verified** cell below means content was returned for the specified revision and path; it is **not** independent legal license clearance, notice completeness, policy effectiveness, or ability to submit a security report. A `404`/not-found result means the **named path** returned GitHub API HTTP 404, not that all alternate paths or security contacts are absent. The report avoids disclosing private contacts.
