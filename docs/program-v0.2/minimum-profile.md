# Minimum independently qualified v0.2 profile

**Proposed, not implemented or released.** One bounded synthetic Linux host, an authenticated versioned rule profile with constitutional enforcement in existing decision components, a durable Orchestrator workflow coordinator, existing Control Plane/Execution Runtime effect boundaries, and independent Qualification of frozen acceptance tests. Reuse existing Manifest, GAX, Replay, ODES and Evidence Pack contracts.

Excluded: multi-host fleet, production identity, live financial settlement, arbitrary OS/network confinement, remote exactly-once effects, distributed transactions, paid models, activation of unqualified adapters, external deployment. No historical v0.1 results automatically transfer.

Minimum acceptance: complete mandatory registry check coverage, deny/hold on invalid or stale policy, durable workflow and reconciliation, no producer oracle writes, exact-source integration negatives, a closed enforcement-coverage inventory in which every reachable in-scope effect is mediated, prevented or excluded (proposed ADR-P08; a declaration that merely lists an unmediated path does not satisfy it), at least one complete real rule family migrated through both registry acceptance levels with independently qualified old and new behavior (proposed; see [s02/registry-and-effects.md](s02/registry-and-effects.md)), local identification of the rule-set and evaluator versions governing each decision, and a separate independent verdict. The final decision remains reserved.
