# S01 planning-defect register

Each defect names the row or step it affects, the evidence (exact source reference, read at the stated revision), an evidence tag (VERIFIED means read at source; INFERRED means reasoned from named sources; REQUIRES INVESTIGATION means not established) and a proposed correction with its lane. Lanes keep the two controllers apart: PROGRAM corrections edit this directory (hub PR, controller #193); QUAL items are Qualification-owned and are listed only so Qualification can decide independently (controller #218), engineering does not edit expectations or verdict logic; OWNER items need an operator decision; HUB-DOC items are small hub documentation fixes scheduled in P1; COMPONENT items would change another repository and need separate authorization. Nothing here is an implementation, and every item is OPEN until a reviewed correction merges.
