# Architecture review checklist

This program borrows ISS V6's authority layers, phased work contracts, mini-sprint planning and machine-readable registers; ISSBench's six-record independent qualification planning is adapted rather than copied. The **49-row original inventory** is retained; S01 must provide an exhaustive crosswalk, exact source citations and reasons for every deferred/merged/superseded item.

Open critical decisions: rule store ownership; identity and canonical policy boundaries; complete source-backed check inventory; evaluator activation/freshness; true independent oracle isolation; bounded adapter bypass surface; durable effect reconciliation; qualified environment; source/lock compatibility; final minimum release scope; credible low/central/high effort model.

Review any number in a document as a proposal unless grounded in source evidence. A doc-only merge cannot qualify runtime. Preserve negative evidence, original failures, reduced-scope qualifications and production/release HOLD.
